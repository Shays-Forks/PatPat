# 💬 Shay's PatPat Fork

Shay's PatPat Fork is a fork of PatPat made to restore **ProxLib support** for **Minecraft 26.1 and 26.2**.

This fork exists to keep PatPat working on newer versions where ProxLib support was removed or broken. The goal is to preserve the original PatPat experience while making it usable again on these versions.

# 📔 Open Source

This fork is open source, so anyone can read, review, and verify the code.
